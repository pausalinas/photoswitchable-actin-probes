# Candidate Selection

This stage evaluates and prioritizes probe designs using multiple structural and energetic criteria.

Rather than optimizing a single score, candidate structures are compared using a multi-objective strategy to identify designs that provide favorable trade-offs across several properties.

## Evaluation Metrics

Representative metrics include:

* Shape complementarity
* Binding energy (ΔΔG)
* Interface buried unsatisfied polar groups
* Cavity formation
* Steric compatibility
* Overall interface quality

## Pareto Selection

Pareto optimization is used to identify candidates for which improvement in one metric would require compromising another metric.

Pareto-optimal structures are prioritized for subsequent computational validation.

## Representative Files

This directory contains example score files, filtering scripts, Pareto analysis outputs, and representative selected candidates.
