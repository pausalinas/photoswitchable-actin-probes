# Probe Extension

This stage extends the docked azobenzene photoswitch with a peptide scaffold.

The photoswitch acts as the initial anchoring element, and additional residues are added to generate a scaffold that can later be cyclized and optimized.

## Design Goals

- Preserve the docked azobenzene orientation
- Grow the scaffold away from the protein surface
- Avoid steric clashes with F-actin
- Maintain geometries compatible with cyclization
- Provide positions for later sequence optimization

## Representative Files

This directory contains example Rosetta inputs and representative structures illustrating scaffold extension from the docked photoswitch.
