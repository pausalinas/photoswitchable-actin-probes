# Azobenzene Docking

This stage places the azobenzene-containing photoswitch into a selected F-actin surface pocket.

The goal is to identify docking poses that provide favorable geometric and energetic interactions while maintaining compatibility with subsequent scaffold growth and photoisomerization.

## Evaluation Criteria

Candidate docking poses can be evaluated using:

- Shape complementarity
- Binding energy
- Steric compatibility
- Pocket occupancy
- Interface quality
- Accessibility for subsequent probe extension

## Representative Files

This directory contains example Rosetta inputs and representative structures illustrating the photoswitch-docking workflow.
