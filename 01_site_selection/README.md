# Site Selection

This stage identifies candidate surface-accessible regions on F-actin for probe design.

Candidate sites are evaluated based on:

- Surface accessibility
- Minimal overlap with known actin-binding interfaces
- Local physicochemical properties
- Geometric compatibility with photoswitch docking
- Sufficient space for subsequent scaffold growth
