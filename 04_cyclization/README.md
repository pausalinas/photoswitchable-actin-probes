# Cyclization

This stage converts the extended linear scaffold into a cyclic peptide architecture.

Cyclization reduces conformational flexibility and constrains the probe into a more defined structural ensemble. In Rosetta, ring closure can be sampled using generalized kinematic closure methods.

## Design Goals

- Form a stable head-to-tail cyclic scaffold
- Preserve the photoswitch orientation
- Avoid steric clashes
- Maintain favorable backbone geometry
- Generate conformations suitable for subsequent sequence optimization

This directory contains example Rosetta inputs and representative cyclic structures generated during the cyclization stage.
